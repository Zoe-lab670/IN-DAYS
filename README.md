## V12 重点
- 月历缩略图改为“内容自适应展示”：先计算当天真实内容的包围范围，再把组合整体映射到日期安全区之外的展示区域。
- 标题、正文、贴纸、照片在月历缩略图中统一放大，但保持相对位置、比例和旋转关系。
- 日期数字仍然是独立层；不显示保护框、不显示保护虚线。
- 一日画布本身的编辑坐标与尺寸逻辑不被月历缩略展示逻辑改写。
- 日期安全区继续限制编辑内容，但范围缩小到只围绕日期数字本身。
