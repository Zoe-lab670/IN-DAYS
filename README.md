# IN DAYS · Day Composition V11

基于 V10 继续优化。本轮根据参考视觉稿收紧“日期独立区 + 月历缩略图比例”表现，目标是让月历里的内容更有存在感，同时保持日期简洁、无明显边框。

## V11 本轮内容
- 日期独立为固定的“日期板块”，画布中不可选中、不可拖动。
- 标题、正文、贴纸、照片全部受“内容安全区”约束，不允许进入日期保护区。
- 拖动、方向键微调、缩放、旋转、复制、自动排版都会重新计算安全位置。
- 旧记录加载时会自动把旧位置规范化到内容安全区，保留标题、正文、贴纸、照片等数据。
- 月历日期改为无背景、无边框的轻量数字，只保留左上角的视觉占位；日期保护区保持不可见，不再占用过大面积。
- 根据参考视觉稿放大月历缩略图内部文字、贴纸和照片的视觉占比，让有记录日期更接近“生活作品墙”，而不是缩小得过小。
- 日期保护区缩小到左上角约 17% × 13.5% 的范围；内容可以使用其余大部分画布，只要不侵入日期区。
- 标题/正文的内容区同步扩大，旧记录加载时继续自动规范位置。
- 保留 233 枚贴纸（107 原始 + 126 补充），仍全部在 app.js。
- 不包含 config.js，替换时保留你现有的 config.js / Supabase 配置。
